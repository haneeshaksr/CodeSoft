# Rule-Based Chatbot Using Python

## Description
This project is a simple Rule-Based Chatbot developed using Python.  
The chatbot responds to user messages using predefined rules and if-else statements.

---

## Features
- Greeting responses
- Answers simple questions
- Interactive conversation
- Exit functionality
- Beginner-friendly project

---

## Technologies Used
- Python
- VS Code
- GitHub

---

## Python Concepts Used
- if-else statements
- loops
- string handling
- user input

---

## How to Run the Project

### Step 1
Install Python on your system.

### Step 2
Save the file as:
```text
chatbot.py
```

### Step 3
Open terminal or command prompt.

### Step 4
Run the command:
```bash
python chatbot.py
```
